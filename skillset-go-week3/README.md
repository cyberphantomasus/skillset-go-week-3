# Skill Set Go — AI/ML Internship — Week 3

TensorFlow/Keras, text classification, prompt engineering, AI-assisted coding.
Offer ID: SSG/AIML/B1/0291

## Structure
- `3.1-tensorflow-keras/` — same feed-forward network built in PyTorch and Keras on identical data/settings, with a fair side-by-side comparison (PyTorch 81.0% vs Keras 77.7% test accuracy; single run, within noise)
- `3.2-text-classification/` — TensorFlow spam classifier on 5,574 real SMS messages (98.6% accuracy, 0.94 spam F1), compared against a TF-IDF + Logistic Regression baseline it roughly ties, with error analysis
- `3.3-prompt-engineering/` — evaluation sheet (xlsx): 4 task types x 3 prompt versions, scored by automated checks
- `3.4-ai-assisted-coding/` — expense-tracker CLI generated by an AI assistant, then audited: v1 passed 5/17 requirement tests, the corrected version passes 17/17; full findings in `AUDIT_NOTES.md`

Each folder has its own README with objective, method, results, limitations and setup instructions.

## Notes
- Task 3.1: import order matters. TensorFlow must be imported after PyTorch training finishes (importing it first crashed the Python kernel in the build environment).
- Task 3.2 dataset: SMS Spam Collection from the public `justmarkham/pycon-2016-tutorial` repository on GitHub.
- Task 3.3: outputs were generated by Claude while the sheet was prepared and scored by script; see the sheet's "Method and limitations" section.
